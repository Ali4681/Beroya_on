# تذكرة Flutter — لغة السائق لـ VIP والنقل السياحي

موجّهة لمطوّر تطبيق الزبون. الـBackend جاهز في `Beroya_on`. **لم يُنفَّذ أي شيء في تطبيق Flutter بعد.** ادمج داخل مشروعكم الحالي.

---

## القواعد غير القابلة للنقاش

1. عند حجز **فئة VIP** (`ride_category.code === 'VIP'`) أو خدمة **نقل سياحي** (`service_type === 'TOURIST'`) يجب أن يختار الزبون لغة السائق قبل التقدير/الإنشاء.
2. أرسل `preferred_driver_language` كـ **ISO 639-1 صغير** (`ar`, `en`, `fr`, `tr`…) — ليس `AR`/`EN`.
3. التوجيه يعرض العرض **فقط** لسائق يتكلم هذه اللغة (لغة الأم أو اللغات الأخرى المسجّلة له). لا تعتمد على ترتيب محلي.
4. لباقي الفئات/الخدمات اللغة اختيارية (افتراضي `ar`) وتُفضَّل فقط في الترتيب دون استبعاد السائقين.

---

## متى تظهر شاشة اختيار اللغة؟

| الحالة | اختيار اللغة |
| --- | --- |
| فئة المركبة `VIP` (أي خدمة) | **إلزامي** |
| خدمة `TOURIST` (نقل سياحي) — بأي فئة | **إلزامي** |
| يومي / عائلي / سيدات / … بدون VIP وبدون سياحي | اختياري أو أخفِ الحقل |

اكتشف الفئة من `GET /customer/ride-categories` (`code`) والخدمة من `GET /customer/services` (`code`).

---

## الحقل في الـAPI

`preferred_driver_language` في:

- `POST /api/v1/go/customer/rides/estimate`
- `POST /api/v1/go/customer/rides`

أمثلة:

```json
{
  "service_type": "TOURIST",
  "ride_category_id": "<uuid>",
  "passengers_count": 2,
  "preferred_driver_language": "en",
  "pickup": { "lat": 33.51, "lng": 36.27 },
  "destination": { "lat": 33.52, "lng": 36.30 }
}
```

```json
{
  "ride_category_id": "<vip-category-uuid>",
  "preferred_driver_language": "fr",
  "type": "IMMEDIATE",
  "pickup": { "lat": 33.51, "lng": 36.27 },
  "destination": { "lat": 33.52, "lng": 36.30 }
}
```

- الاستجابة تعيد نفس الرمز بصيغة ISO (`en` وليس `EN`).
- بدون الحقل على VIP/سياحي → `VALIDATION_ERROR` على `preferred_driver_language`.
- رمز غير معروف (`xx`) → `VALIDATION_ERROR`.

---

## واجهة الاختيار (اقتراح)

1. بعد اختيار الخدمة/الفئة وقبل التقدير: خطوة «لغة السائق».
2. قائمة قابلة للبحث. ابدأ بعرض شائع للسياحة ثم الباقي:

| code | مثال تسمية عربية |
| --- | --- |
| `ar` | العربية |
| `en` | الإنجليزية |
| `fr` | الفرنسية |
| `tr` | التركية |
| `de` | الألمانية |
| `ru` | الروسية |
| `fa` | الفارسية |
| `zh` | الصينية |

القائمة الكاملة = رموز ISO 639-1 المعتمدة في الباك (`WORLD_LANGUAGE_CODES` في `drivers/world-languages.ts`). يمكن نسخها ثابتاً في التطبيق أو مزامنتها يدوياً مع الباك.

3. نص توضيحي: «سنعرض الطلب فقط على سائقين يتحدثون هذه اللغة».
4. أعد إرسال نفس القيمة في `estimate` و`create` (لا تغيّرها بينهما).

---

## سلوك التوجيه (للمعلومة فقط)

- VIP أو `TOURIST` + لغة مختارة → استبعاد أي سائق لا يتكلمها.
- غير ذلك → السائق المطابق يرتفع في الترتيب؛ الباقون يبقون مرشّحين.
- إن لم يوجد سائق مطابق قد تنتهي الرحلة بـ `FAILED_NO_DRIVER` — اعرض رسالة واضحة مثل: «لا يوجد سائق متاح بهذه اللغة حالياً».
