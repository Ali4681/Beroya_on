# تذكرة Flutter — شارة الخصم / كود الخصم (كاش + تعويض الشركة)

موجّهة لتطبيقي **الزبون** و**السائق**. الشارة من الداشبورد: **إدارة → شارات الخدمات**. الأكواد من **أكواد الخصم**.

---

## القاعدة المالية (كود وشارة سواء)

مثال: أجرة **20 000** · خصم **50%**

| | |
| --- | --- |
| الزبون | يدفع **10 000 كاش** فقط — **لا حجز** من محفظته |
| طريقة الدفع | تُفرَض **CASH** تلقائياً عند وجود خصم (كود أو شارة بنسبة) |
| الشركة | تضيف **10 000** لمحفظة السائق (`discount_subsidy` / `DISCOUNT_SUBSIDY`) |
| العمولة | على **20 000** (الإجمالي) |

«حجز الكود» = قفل استخدام الكود على الرحلة فقط، مو فلوس الزبون.

---

## الزبون

1. شارة: `GET /customer/services` → `offer` (`PROMOTION` أو `DISCOUNT`).
2. تقدير: `estimated_fare` كامل · `discount_amount` · `final_fare` ما يدفعه.
3. إنشاء الرحلة:
   - كود: أرسل `discount_code_id`.
   - شارة `PROMOTION` بنسبة: لا تحتاج `discount_code_id`.
   - حتى لو أرسلت `payment_method: WALLET` مع خصم، الاستجابة تكون `payment_method: CASH`.
4. بعد الإنهاء: ادفع/اعرض `cash_due` = المبلغ بعد الخصم.

```dart
// مع خصم: لا تعتمد على محفظة الزبون للدفع
final payCash = (estimate.discountAmount ?? 0) > 0
    || service.offer?.percentage != null;
```

---

## السائق — الفاتورة

| حقل | مثال |
| --- | --- |
| `gross_fare` | 20 000 |
| `customer_payable` / `cash_due` | 10 000 (استلم كاش) |
| `discount_subsidy` | 10 000 (أُضيف لمحفظتك من الشركة) |
| `driver_earnings` | على الإجمالي − العمولة |

---

## اختبار

- [ ] كود 50% + طلب WALLET → الرحلة `CASH` وبدون خصم من محفظة الزبون.
- [ ] إنهاء: كاش 10 000 + `discount_subsidy` 10 000 + عمولة على 20 000.
- [ ] شارة بنسبة بدون كود → نفس السلوك.
- [ ] بدون خصم + WALLET → الحجز من المحفظة كالسابق.
